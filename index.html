\(\LaTeX\)

“LaTeX (/ˈlɑːtɛk/ LAH-tek or /ˈleɪtɛk/ LAY-tek, often stylized as \(\LaTeX\)) is a software system for typesetting documents. LaTeX markup describes the content and layout of the document, as opposed to the formatted text found in WYSIWYG word processors1.”

  1. https://en.wikipedia.org/wiki/LaTeX

Why use \(\LaTeX\)?

Strengths

  • Beautiful mathematics
  • Consistent formatting, automatically
  • Numbering and cross-references that update themselves
  • References and bibliographies managed for you
  • Plain text: works well with version control

Trade-offs

  • A learning curve
  • You write markup, then compile
  • Fine layout control can be fiddly
  • Not always ideal for heavily visual documents

How it works

  • You edit source; the engine compiles it into a PDF
  • If something is wrong, the log tells you where

\usepackage{}

Packages expand the capabilities of \(\LaTeX\). Some examples are:

  • amsmath: advanced maths
  • graphicx: images
  • xcolor: colours
  • booktabs: nicer tables
  • hyperref: clickable links and references

Packages are loaded in the preamble, before \begin{document}.

Sections, paragraphs and text

  • \section{}, \subsection{} create numbered headings
  • \tableofcontents builds the contents list. Compile twice to update it
  • A blank line starts a new paragraph
  • \textbf{} for bold, \emph{} for emphasis
\documentclass{article}

\begin{document}

\tableofcontents

\section{Introduction}
This is a paragraph. A blank line
starts a new one. Use \textbf{bold}
and \emph{emphasis}.

\subsection{Background}
More text.

\end{document}

Lists

  • itemize gives bullet points
  • enumerate gives numbered items
  • Each entry starts with \item
  • Lists can be nested
\begin{itemize}
  \item First point
  \item Second point
\end{itemize}

\begin{enumerate}
  \item Step one
  \item Step two
\end{enumerate}

Mathematics

  • Inline expressions go between two $ signs
  • Display equations use the equation environment
    • Numbered automatically
    • equation* (needs amsmath) is unnumbered
  • align lines up multi-line equations

\usepackage{amsmath}

\begin{document}

\end{equation}

Cross-referencing

Equations can be referred to from the main text.

  • Two commands do the job:
    • \label{} names the equation
    • \ref{} points to it
  • Put \label inside the environment
  • Use ~ before \ref to avoid a line break
  • Compile twice so numbers update
\documentclass{article}
\usepackage{amsmath}

\begin{document}

Energy is given by Eq.~\ref{eq:energy}.

\begin{equation}
  E = mc^2
  \label{eq:energy}
\end{equation}

\end{document}

Figures

  • figure is a float: \(\LaTeX\) decides where it lands
    • [htbp] = here, top, bottom, own page
  • \includegraphics inserts the image
    • Dimensions go inside [ ]
    • The filename goes inside { }
    • Upload the image to your Overleaf project first
  • \caption{} first, then \label{}
  • Refer to it with Figure~\ref{fig:myfig1}
\documentclass{article}
\usepackage{graphicx}

\begin{document}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=8cm]{myplot}
  \caption{My plot.}
  \label{fig:myfig1}
\end{figure}

See Figure~\ref{fig:myfig1}.

\end{document}

Tables

  • table is a float, like figure
  • tabular draws the table itself
    • {lcc}: one letter per column: left, centre, right
    • & separates cells, \\ ends a row
  • booktabs gives clean rules: \toprule, \midrule, \bottomrule
  • Put \caption and \label above the table (usual convention)
\documentclass{article}
\usepackage{booktabs}

\begin{document}

\begin{table}[htbp]
  \centering
  \caption{Results.}
  \label{tab:results}
  \begin{tabular}{lcc}
    \toprule
    Group & Mean & SD \\
    \midrule
    A & 1.2 & 0.3 \\
    B & 1.8 & 0.4 \\
    \bottomrule
  \end{tabular}
\end{table}

\end{document}

\(Bib\TeX\)

  • \(Bib\TeX\) is a bibliography database file format
  • It is the basis for citations and references in \(\LaTeX\)
  • Files are saved with the .bib extension
  • Each entry has a type, a key and field = {value} pairs
  • You rarely type these by hand: reference managers, Google Scholar and journal websites can export .bib
@article{smith2024,
  author  = {Smith, Jane},
  title   = {An example article},
  journal = {Journal of Examples},
  year    = {2024}
}

References

  • \bibliographystyle{plain} sets the citation style
    • Several styles are built in
    • More can be added with .bst files
  • \bibliography{refs} prints the references cited and reads refs.bib
  • \cite{} cites an entry. The text in braces is the key from the .bib file
  • After adding citations, recompile (sometimes twice) so they resolve
\documentclass{article}

\begin{document}

As previously seen elsewhere
\cite{smith2024}.

\bibliographystyle{plain}
\bibliography{refs}

\end{document}

\(Bib\TeX\) or biblatex?

  • \(Bib\TeX\) (with natbib): long-established. Many journal templates require it
  • biblatex: more flexible styles and easier customisation
  • Both use the same .bib file
  • When using a journal template, follow its instructions
\usepackage[style=authoryear]{biblatex}
\addbibresource{refs.bib}

...

\parencite{smith2024}

\printbibliography

When things go wrong

Read the first error in the log: later ones are often knock-on effects.

Message Usual cause
Undefined control sequence Typo in a command, or a missing \usepackage
Missing $ inserted _ or ^ (or a maths symbol) used outside maths mode
File not found Wrong image name or path, or the file was not uploaded
Runaway argument / Missing } Unbalanced braces
\begin{x} ended by \end{y} A missing or mismatched \end
?? in the PDF A \ref or \cite that has not resolved yet: recompile

Special characters need a backslash: \%, \&, \$, \#, \_, \{, \}

Practical session

  1. Create a new blank project and compile “Hello, world”
  2. Add a title, author and date with \maketitle
  3. Add two sections and a bulleted list
  4. Write the quadratic formula as a numbered equation and refer to it in the text
  5. Upload an image and insert it as a figure with a caption
  6. Build a small table with booktabs
  7. Create refs.bib, add one entry and cite it

Stretch: try a journal template, or switch to biblatex
